Python 3.9 Installation & Dependency Setup Guide

Document: SETUP-TDMS-001 For: TDMS Report Generator (tdms_report.py) Rev A

1. Overview

This guide covers the complete setup required to run tdms_report.py on a Windows machine connected to LabVIEW. It includes:

  • Python 3.9.x 64-bit installation
  • Verifying PATH configuration
  • Installing all required Python packages
  • Running the provided setup_dependencies.cmd batch file
  • Verifying the setup is working
Why Python 3.9? LabVIEW 2021+ Python Node requires Python 3.x. Python 3.9 is the most stable and widely compatible version for LabVIEW integration.

3. Step-by-Step Installation

Step 1 — Download Python 3.9.13 (64-bit)

  1. Open the official Python download page

    Go to: https://www.python.org/downloads/release/python-3913/

    ⬇ Download Python 3.9.13 (64-bit)
  2. Select the correct installer

    Scroll to the Files section at the bottom of the page and click:

    Windows installer (64-bit) — file name: python-3.9.13-amd64.exe

Step 2 — Run the Installer

  1. Double-click the downloaded installer

    The installer window will open.

  2. Check "Add Python 3.9 to PATH"

    At the bottom of the first installer screen, make sure this checkbox is checked before clicking Install.

    ⚠ If you skip this step, Python will not be found by LabVIEW or the CMD setup file.
  3. Click "Install Now"

    Wait for the installation to complete (about 2–3 minutes).

  4. Click "Disable path length limit" (if prompted)

    If a final screen asks to disable Windows path length limit — click it. This avoids issues with long file paths.

  5. Click "Close"

    Installation is complete.

Step 3 — Verify Python Installation

  1. Open Command Prompt

    Press Win + R, type cmd, press Enter.

  2. Run the version check 
    python --version

    Expected output:

    Python 3.9.13
    If you see this — Python is correctly installed and on PATH.
  3. Verify it is 64-bit 
    python -c "import platform; print(platform.architecture())"

    Expected output:

    ('64bit', 'WindowsPE')

5. Automatic Setup Using CMD File

A batch script setup_dependencies.cmd is provided. It automatically installs all packages in one step.

  1. Copy setup_dependencies.cmd to your project folder

    For example: D:\Projects\Software Repo\LAB-IQ 150\WO 2476\v04\Report Loop\

  2. Right-click → "Run as Administrator"

    This ensures pip can write to Python's site-packages directory.

    ⚠ Always run the CMD file as Administrator to avoid permission errors.
  3. Watch the output — you will see each package being installed 
    [1/6] Upgrading pip...
[2/6] Installing numpy...
[3/6] Installing matplotlib...
[4/6] Installing scipy...
[5/6] Installing nptdms...
[6/6] Installing Pillow...

[OK] numpy         1.26.4
[OK] matplotlib    3.8.4
[OK] scipy         1.13.0
[OK] nptdms        0.12.0
[OK] Pillow        10.3.0
  4. Press any key to close

    All packages are now installed and ready to use.

6. Manual Installation (Alternative)

If you prefer to install packages manually, open Command Prompt and run each command:

python -m pip install --upgrade pip
python -m pip install numpy
python -m pip install matplotlib
python -m pip install scipy
python -m pip install nptdms
python -m pip install Pillow

8. Troubleshooting

ErrorCauseFix
python is not recognized Python not on PATH Reinstall and check "Add Python to PATH"
ModuleNotFoundError: nptdms Package not installed Run setup_dependencies.cmd as Administrator
LabVIEW Python Node error at index 0 Parameter count mismatch Use generate_report_simple which accepts any number of args
UnicodeEncodeError: charmap Non-ASCII character in log file Already fixed in latest tdms_report.py
Report generated but no logos visible Logo path incorrect or file not found Use full absolute path e.g. C:\Logos\company.png
LabVIEW uses wrong Python version Multiple Python versions installed Set Python Path explicitly in LabVIEW Python Session open
